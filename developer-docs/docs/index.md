# RADR — Developer Documentation

Firmware for the Research and Desire wireless remote (ESP32, PlatformIO).

Source lives at the repository root in the standard PlatformIO layout (CERN-OHL-S v2).

## Topics

- **BLE** — device scanning and protocol bridges
- **Device registry** — supported OSSM, Lovense, and Buttplug IO devices
- **OTA** — over-the-air firmware updates

User guides: [docs.researchanddesire.com/radr](https://docs.researchanddesire.com/radr/).
